# Md Rafi Ur Rashid — personal website

A responsive, accessible academic portfolio for https://rafi-ur-rashid.github.io/.

## Publish with GitHub Pages

1. Open this repository's **Settings → Pages**.
2. Under **Build and deployment**, select **Deploy from a branch**.
3. Select **main** and **/ (root)**, then **Save**.
4. GitHub will show the published URL after deployment finishes.

If Pages is unavailable because the repository is private, use a GitHub plan that supports private-repository Pages or change this portfolio repository to public under **Settings → General → Danger Zone → Change repository visibility**. Only the portfolio files in this repository will be exposed by that change.

## Editing

- Edit `index.html` for biography, publications, news, and links.
- Edit `style.css` for colors, type sizes, spacing, and responsive layouts.
- Replace `assets/portrait.jpg` to update the portrait.
- There is no package installation or build step. Open `index.html` in a browser or run `python3 -m http.server 8000` locally.
- Add a CV file and navigation link when an approved current CV is available.
